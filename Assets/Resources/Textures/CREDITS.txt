Photo-scanned textures, all CC0 (public domain), source: Poly Haven (https://polyhaven.com), 1K diffuse maps, resized.
Files are JPEG data stored with the .bytes extension (loaded as TextAsset, decoded with ImageConversion.LoadImage so they are CPU-readable without import settings).
asphalt.bytes  1024 Poly Haven "asphalt_track"       CC0  (EnvTex.RoadDetail R, 3.2 m tile; was 512)
kerbconc.bytes 1024 Poly Haven "concrete_floor_worn_001"  CC0  (EnvTex.RoadDetail G: the kerbs' concrete)
leafspray.bytes 1024x512 PNG  ambientCG "LeafSet002", "LeafSet005"  CC0  (cut-out sprays for EnvTex.Foliage's leaf clusters)
(asphalt / kerbconc / leafspray: Tools/Photo/make_photos.py, from GitHub mirrors of the original CC0 files, Docs/ASSETS.md)
